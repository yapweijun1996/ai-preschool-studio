## Firefox reload-count root cause

Firefox emitted `PWA load event 1 about:blank`, followed by two same-URL `PWA frame navigated true http://127.0.0.1:4180/ai-preschool-studio/` records and `PWA load event 2 http://127.0.0.1:4180/ai-preschool-studio/`. After clicking apply, the traced failure snapshot still showed version `0.3.0-a` and “The update couldn’t be installed.” `src/pwa/index.tsx:221-229` refuses reload when the 30 s session guard is active; `:369-382` invokes that guard on `controllerchange`. This was a test-counting assumption, not a product reload. `e2e/pwa-update.spec.ts:73-74,154-155,213-215,234-236` now count app document loads only, excluding `about:blank`. Full Firefox suite passes (68 tests).
